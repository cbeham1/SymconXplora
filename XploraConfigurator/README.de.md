# Xplora Configurator

Listet die Uhren des Xplora-Kontos der verbundenen Instanz „Xplora Cloud“ und legt auf Wunsch für jede Uhr eine
Instanz „Xplora Watch“ an.

### 1. Funktionsumfang

* Listet alle Uhren des Kontos mit Name und Uhren-ID
* Legt die Instanzen „Xplora Watch“ auf Klick an („Erstellen“)
* Zeigt vorhandene Instanzen, deren Uhr nicht mehr im Konto ist

### 2. Voraussetzungen

- IP-Symcon 7.0 oder neuer
- aktive Instanz „Xplora Cloud“

### 3. Installation

„Instanz hinzufügen“ → „Xplora Configurator“. IP-Symcon legt die Instanz „Xplora Cloud“ an, falls noch keine existiert.

### 4. Konfiguration

Keine Einstellungen. Die Liste zeigt die Uhren der verbundenen Instanz „Xplora Cloud“. Ist diese nicht aktiv,
erscheint der Hinweis, deren Zugangsdaten zu prüfen.
