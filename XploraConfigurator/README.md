# Xplora Configurator

[Deutsche Anleitung](README.de.md)

Lists the watches of the Xplora account of the connected Xplora Cloud instance and creates an Xplora Watch instance for each watch on request.

### 1. Features

* Lists all watches of the account with name and watch ID
* Creates the Xplora Watch instances on request ("Create")
* Shows existing instances whose watch is no longer in the account

### 2. Requirements

- IP-Symcon 7.0 or newer
- An active "Xplora Cloud" instance

### 3. Installation

"Add instance" → "Xplora Configurator". IP-Symcon creates the Xplora Cloud instance if none exists.

### 4. Configuration

No settings. The list shows the watches of the connected Xplora Cloud instance.
